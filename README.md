# 🧱 LEGO Architecture Store

Uma loja virtual desenvolvida em dupla como projeto acadêmico da **Fatec Mauá**, com o objetivo de aplicar conhecimentos de desenvolvimento web e banco de dados na construção de uma aplicação funcional.

A proposta consiste em criar uma loja especializada em conjuntos e projetos de LEGO inspirados na arquitetura, reunindo construções que representam edifícios, monumentos e estruturas arquitetônicas em uma experiência de compra on-line.

## 🎯 Objetivo do projeto

Desenvolver uma aplicação web funcional a partir de um tema livre, integrando tecnologias de front-end e back-end, além de conceitos de banco de dados, autenticação e gerenciamento de informações.

## 🚀 Funcionalidades

- 🏠 Página inicial da loja.
- 🧱 Catálogo e visualização de produtos.
- 👤 Cadastro e autenticação de usuários.
- 🛒 Carrinho de compras.
- 💳 Fluxo de finalização de compras.
- 📦 Registro e consulta de pedidos.
- ✅ Confirmação de pedidos.
- ⚙️ Área administrativa.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e apresentação visual.
- **JavaScript:** interatividade e funcionalidades no navegador.
- **PHP:** processamento e lógica da aplicação.
- **MySQL:** armazenamento e gerenciamento de dados.
- **phpMyAdmin:** administração do banco de dados.
- **USBWebServer:** ambiente de execução local.
- **Git e GitHub:** versionamento e compartilhamento do código.
